# New client checklist

- [ ] Create a fresh destination with `npm run client:new`; use a separate repository.
- [ ] Confirm business ID, real name, owner, location/areas, contacts and hours.
- [ ] Set colors, typography, logo/mark, layout and approved asset paths.
- [ ] Replace neutral headlines, page copy, service descriptions, values and process.
- [ ] Configure service IDs, fields, contact method, CTA and honest next steps.
- [ ] Confirm any free estimate claim, credentials, review figures and testimonial permissions.
- [ ] Disable unneeded sections/features; verify navigation, empty states and 404s.
- [ ] Supply licensed, client-approved images. Label demonstration assets explicitly.
- [ ] Create new owner credentials and VAPID keys. Never reuse another client's private env/database.
- [ ] Configure a dedicated persistent data directory, backup and retention policy.
- [ ] Review privacy policy text, cookie/session handling and notification providers.
- [ ] Set final HTTPS origin, SEO/social image, indexing and any legacy redirects.
- [ ] Run configuration/asset checks, lint, TypeScript, tests and production build.
- [ ] Verify mobile/desktop form errors, success modal, keyboard navigation and owner authorization.
- [ ] Install from HTTPS and test real-device notifications with the app closed.
- [ ] Run the retry worker/scheduler and verify failure/recovery behavior.
- [ ] Obtain client approval before public deployment; record maintenance responsibilities.
